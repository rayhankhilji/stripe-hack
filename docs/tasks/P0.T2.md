# P0.T2 — Produce the Ghost brand kit

## Goal
Recreate the Ghost mark from the brand board as clean, production vectors and ship them in the forms the app needs. This is the first thing judges see, so curve quality matters. Build it as a geometric construction, not a traced blob.

## Inputs
`docs/brand/brand-board.webp`: wordmark on forest (top-left), 3D symbol (top-middle), app icons (bottom row). `docs/brand/BRAND.md` gives the hex values, logo rules and clear space.

## Interface to implement
1. **`brand/` (source of truth, SVG only, `viewBox`-based, no raster data, no filters, no gradients):**
   - `brand/symbol.svg`: the four-point bloom.
     - It is a soft four-point star whose arms have rounded tips. A curved "fold" cuts the lower-left lobe, creating the crescent-shaped negative space visible on the board.
     - Build it from cubic Béziers on a 512×512 grid, symmetric about the diagonal where the board is symmetric.
     - Use one `<path>` for the body and either a second path for the fold or `fill-rule="evenodd"` for the cut-out.
     - Fill is `currentColor`.
   - `brand/wordmark.svg`: lowercase "ghost" set in **Fraunces SemiBold** (Google Fonts, OFL), converted to outlines (use `opentype.js` in a throwaway script outside the repo, or any font-to-path tool). Use slightly tightened tracking (−1%) and no live text. Fill is `currentColor`.
   - `brand/lockup-horizontal.svg`: symbol + wordmark. Symbol height = x-height × 1.35, gap = 0.35 × symbol width, baseline-aligned optically.
   - `brand/app-icon-{forest,petal,navy}.svg`: 1024×1024, rounded-square background (radius 22%), symbol centred at 56% of the width. Colours:

     | Variant | Symbol | Background |
     |---|---|---|
     | forest | Petal | Forest |
     | petal | Punch | Petal |
     | navy | Petal | Navy |
   - `brand/README.md`: construction notes, clear-space rule, the do/don't list from BRAND.md, and a colour table.
2. **`apps/web/public/brand/`:** copies of the SVGs above, plus `og.png` (1200×630: forest background, petal lockup centred) rendered from SVG via a script using `sharp` or Playwright screenshot. Keep the generation script under `brand/scripts/` and run it with `npx` (do not add it as a workspace dependency).
3. **Next app icons:**
   - `apps/web/src/app/icon.svg` (forest app icon),
   - `apps/web/src/app/apple-icon.png` (180×180, rendered),
   - `apps/web/src/app/favicon.ico` (16/32/48 rendered from the forest icon; must be legible at 16px).
4. **`apps/web/src/components/ghost/logo.tsx`:**
   ```tsx
   export type LogoProps = { variant?: "lockup" | "symbol" | "wordmark"; size?: number; title?: string; className?: string };
   export function Logo(props: LogoProps): JSX.Element
   ```
   - Inline SVG with the same paths, `fill="currentColor"`, `role="img"` with `<title>` defaulting to "Ghost", and `size` = rendered height in px (default 24).
   - Colour comes from the parent's text colour. Do not hard-code colours in the component.

## Rules
- Paths must be clean: no more than about 40 nodes for the symbol, no self-intersections, rounded joins.
- **Pass the 16px test:** render `favicon.ico` at 16px and check that the four points and the fold are distinguishable. Include a 4× zoom screenshot of the 16px render in the PR.
- No raster images inside SVGs. No gradients, filters or shadows.

## Acceptance criteria
- T-F11-AC7 — Given the app renders `<Logo variant="lockup" />` inside a forest panel with petal text colour, When the page loads, Then the SVG has an accessible name "Ghost" and inherits `currentColor`. Covered by `logo.test.tsx` (Testing Library; it runs once P0.T1 lands, so before that, verify by rendering a standalone HTML file with Playwright).
- Given the three app-icon SVGs, When rendered at 32px and 1024px, Then the symbol is centred within ±1% and the 16px favicon remains recognisable (PR screenshots).

## Not done if
- The symbol is a generic four-point star or sparkle without the folded negative-space crescent.
- Any SVG contains embedded raster data, gradients, filters or live `<text>`.
- Colours are hard-coded inside `logo.tsx`.
