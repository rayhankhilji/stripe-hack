# P0.T1 — Scaffold the pnpm monorepo, toolchain and empty packages

## Goal
Every other card builds on this skeleton, so it must be boring, correct and fast. When it's done, `pnpm install && pnpm typecheck && pnpm lint && pnpm test && pnpm build` passes on a clean clone, and every package in INSTRUCTIONS §4 exists with the right name, its dependencies, and an import boundary.

## Inputs
- INSTRUCTIONS §3 (locked stack and versions) and §4 (layout).
- Installed toolchain in the build containers: Node 22, pnpm 10.28.0. Docker and psql are available.
- Existing `scripts/check-ownership.mjs` and `scripts/check-slop.mjs` (already committed; wire them up, do not edit them).

## Interface to implement
1. **Root `package.json`.**
   - `"name": "ghost"`, `"private": true`, `"packageManager": "pnpm@10.28.0"`, `"engines": {"node": ">=22"}`.
   - Scripts, exactly these names:
     - `dev` → `pnpm --filter @ghost/web dev`
     - `build` → `pnpm -r build`
     - `typecheck` → `pnpm -r typecheck`
     - `lint` → `eslint .`
     - `format` → `prettier --write .`
     - `test` → `vitest run`
     - `test:e2e` → `playwright test`
     - `db:generate` → `pnpm --filter @ghost/db db:generate`
     - `db:migrate` → `pnpm --filter @ghost/db db:migrate`
     - `ingest` → `pnpm --filter @ghost/ingest ingest`
     - `era:record` → `pnpm --filter @ghost/era record`
     - `demo:reset` → `tsx scripts/demo-reset.ts`
     - `check:ownership` → `node scripts/check-ownership.mjs`
     - `check:slop` → `node scripts/check-slop.mjs`
     - `check:docs` → `node scripts/check-docs.mjs`

     Scripts whose target does not exist yet must still be declared. They will fail until the owning card lands, which is expected.
2. **`pnpm-workspace.yaml`:** `apps/*`, `packages/*`.
3. **Packages.** Each gets `package.json` (`"type": "module"`, `"main"`/`"types"` → `src/index.ts`, i.e. source-only workspace packages consumed by Next via `transpilePackages`), `tsconfig.json` extending `tsconfig.base.json`, and `src/index.ts` containing only `export {};`. Packages and their runtime dependencies:

   | Package | Path | Dependencies (exact majors) |
   |---|---|---|
   | `@ghost/shared` | packages/shared | zod@^4.6 |
   | `@ghost/db` | packages/db | drizzle-orm@^0.45, postgres@^3, @electric-sql/pglite@^0.5 · dev: drizzle-kit@^0.31 |
   | `@ghost/era` | packages/era | @modelcontextprotocol/sdk@^1.32 |
   | `@ghost/ingest` | packages/ingest | (workspace deps only) · dev: tsx |
   | `@ghost/knowledge` | packages/knowledge | (workspace deps only) |
   | `@ghost/billing` | packages/billing | (only @ghost/shared) |
   | `@ghost/stripe` | packages/stripe | stripe@^23 |
   | `@ghost/core` | packages/core | (workspace deps only) |
   | `@ghost/agents` | packages/agents | @mastra/core@^1.77, @mastra/pg@^1.31, @ai-sdk/openai@^4, ai@^7 |
   | `@ghost/web` | apps/web | next@16.4, react@19, react-dom@19, @tanstack/react-query@^5, motion@^14, lucide-react, geist@^1.7, @radix-ui/react-* (dialog, dropdown-menu, tabs, tooltip, popover, slot), clsx, tailwind-merge, class-variance-authority · dev: tailwindcss@^4.3, @tailwindcss/postcss, @testing-library/react, @testing-library/jest-dom, jsdom |

   Workspace internal deps follow the dependency direction in INSTRUCTIONS §4. Root dev deps: `typescript@~5.9.3`, `eslint@^9`, `typescript-eslint@^8`, `@next/eslint-plugin-next`, `eslint-plugin-react-hooks`, `prettier@^3`, `vitest@^5`, `@vitest/coverage-v8`, `@playwright/test@~1.64`, `msw@^3`, `tsx`, `@types/node`.
4. **`tsconfig.base.json`:**
   - Compiler options: `strict`, `noUncheckedIndexedAccess`, `exactOptionalPropertyTypes: false`, `module: "esnext"`, `moduleResolution: "bundler"`, `target: "es2022"`, `verbatimModuleSyntax`, `skipLibCheck`.
   - `paths` are not needed (workspace packages resolve through node_modules).
   - Each package's `typecheck` script is `tsc --noEmit`.
5. **`eslint.config.mjs` (flat config).**
   - Include typescript-eslint recommended-type-checked (with project service), next plugin for `apps/web`, and react-hooks.
   - Rules:
     - `@typescript-eslint/no-explicit-any: error`, `no-console: ["error", {allow: ["warn","error"]}]` (scripts/ and e2e/ excepted), `@typescript-eslint/no-floating-promises: error`.
     - **`no-restricted-imports` per package** to enforce the dependency direction: `@ghost/billing` and `@ghost/shared` may not import any other `@ghost/*` (billing may import shared); no package may import `@ghost/web`; only `@ghost/era` may import `@modelcontextprotocol/sdk`; only `@ghost/stripe` may import `stripe`; only `@ghost/agents` may import `@mastra/*`, `ai` or `@ai-sdk/*`.
6. **`apps/web`.**
   - `next.config.ts` with `transpilePackages: ["@ghost/*" packages listed explicitly]` and `serverExternalPackages: ["@electric-sql/pglite", "@mastra/core", "@mastra/pg"]`.
   - `typedRoutes: true`.
   - Tailwind 4 via `@tailwindcss/postcss`.
   - `src/styles/globals.css` contains `@import "tailwindcss";` only (P0.T6 owns tokens later).
   - `src/app/layout.tsx` is a minimal root layout.
   - `src/app/page.tsx` renders the text "Ghost" in a `<main>`. It is replaced by P0.T6, and is the only allowed temporary page.
7. **`vitest.workspace.ts`:** one project per package plus `apps/web` (jsdom environment for web). Each package has a `test/smoke.test.ts` asserting its index module imports.
8. **`playwright.config.ts`:** `testDir: "e2e"`, `baseURL: process.env.E2E_BASE_URL ?? "http://localhost:3000"`, chromium only, `webServer` = `pnpm dev` when `E2E_BASE_URL` is unset. Chromium is pre-installed (`PLAYWRIGHT_BROWSERS_PATH=/opt/pw-browsers`), so never run `playwright install`. `e2e/smoke.spec.ts` loads `/` and expects the text "Ghost".
9. **`.gitignore`:** node_modules, .next, coverage, playwright-report, test-results, .env*, except `.env.example`, `services/cognee/data/`, `*.tsbuildinfo`.

## Rules
- Use exactly the versions above. If a version fails to resolve, pick the newest of the same major and note it in the PR.
- No source code beyond what is listed. No UI beyond the single text page. No CI workflow (P0.T11 owns CI).
- Do not create `.env` files. `.env.example` is owned by the docs and already exists.

## Acceptance criteria
- T-F14-AC4 — Given a clean clone, When `pnpm install && pnpm typecheck && pnpm lint && pnpm test && pnpm build` runs, Then every command exits 0. And `pnpm test:e2e` passes `e2e/smoke.spec.ts` against `pnpm dev`.
- Given `packages/billing/src/index.ts` imports `@ghost/db`, When `pnpm lint` runs, Then it fails with a `no-restricted-imports` error. Show this temporary change in the PR body, then revert it.
